## 1. What Is Grid Trading on Bybit?

In one sentence: **grid trading automatically places a series of evenly spaced buy and sell orders inside a price range you define, capturing the difference as price oscillates.**

The logic is simple:

1. You divide a price range into "grids."
2. Price falls one grid → an automatic buy.
3. Price rises one grid → an automatic sell.
4. Price keeps oscillating inside the range → you repeatedly capture the spread.

**Core idea: a grid earns from volatility, not direction.** You do not need to predict up or down — only that price will swing within the range.

## 2. Four Market Conditions: When It Works, When It Does Not

| Condition | Grid performance | Explanation |
|:---|:---|:---|
| Range-bound | ✅ Ideal | Repeated fills steadily accumulate the grid spread |
| Slow uptrend | ⚠️ Partly usable | Keeps selling, may empty the position early and miss the rest of the move |
| Sharp downtrend | ❌ Unsuitable | Keeps buying into a falling market — stuck and underwater |
| Sharp uptrend | ⚠️ Unsuitable | Sells out quickly, then watches price keep rising |

**Conclusion:**&#8203; grid trading is a ranging-market tool. If you expect a strong one-way move, a grid is usually the wrong choice.

## 3. Spot Grid vs Futures Grid

| Item | Spot grid | Futures grid |
|:---|:---|:---|
| Instrument | Spot (e.g. BTC/USDT) | Futures (long/short grids available) |
| Leverage | None | Yes, amplifying risk |
| Liquidation risk | None (but you can get stuck) | **Yes, liquidation risk** |
| Capital efficiency | Lower | Higher |
| Best for | Beginners, conservative users | Experienced traders who can bear liquidation risk |

> **Beginners should start with a spot grid.** A futures grid is more capital-efficient, but in a one-way move you can be liquidated outright — with no chance to wait for a recovery.

## 4. Five Parameters to Decide Before You Start

| Parameter | What you decide | Key consideration |
|:---|:---|:---|
| Price range (upper/lower) | Where price should run | Too narrow ⇒ easy to break out; too wide ⇒ grids too far apart |
| Number of grids | How many divisions | More grids ⇒ smaller spacing ⇒ more fee drag |
| Size per grid / total input | How much per grid | Determines per-grid profit and total capital needed |
| Trigger price | When it starts | Avoid starting in an obvious one-way trend |
| Stop conditions | When it shuts off | Set take-profit, stop-loss, or stop-on-breakout |

**These five interact:**&#8203; more grids mean smaller spacing, which means fees eat a larger share — exactly the point of the next section.
