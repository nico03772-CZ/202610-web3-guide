## 1. What Is a Bybit Referral Code?

A referral code is an **identifier string** in an exchange's referral program, usually letters and numbers. Its job:

## 2. Referral Code vs. Regular Coupon — Not the Same Thing

People conflate these constantly; the differences matter:

| Factor | Referral code | Coupon / promo code |
|:---|:---|:---|
| When it binds | **Only at registration** | Any time after registering |
| Validity | Long-term (follows the relationship) | Fixed expiry |
| What it affects | Trading fee discount | Usually a one-off reward or credit |
| Stacking | Stacks with things like token fee payment | Per campaign rules; rarely stackable |

**Key takeaway**: a referral code is a **long-term rate advantage**; a coupon is a **one-time perk**. Miss the code and the rate discount is gone for good; miss a coupon and the next campaign is around the corner.
